# 2025-09-24 优化与改造汇总

> 本文档整理了今日在 NextAgentLite 中完成的优化与改造项，涵盖模型加载统一、Rerank 集成、构建页（工作室）交互优化、已发布智能体的路由与运行时设置、嵌入页 UI 与交互、后端 API 补全与问题修复等方面。

## 摘要
- 统一使用 9050 网关 `/v1/models/enabled` 装载模型（chat/embedding/rerank），并在前端以 Tag 标注“默认/厂商”。
- 新增 Rerank 供应商工厂，接入硅基流动兼容协议（/v1/rerank），并在混合检索路径中启用精排，失败回退领域加权。
- 构建页改为“保存=草稿，导出=生成我的智能体”，新增草稿多版本管理与弹出式操作分组；修复对话测试“无响应”。
- 已发布智能体：顶角启用开关（禁用/删除即 404）、设置弹窗（模型/多轮/最大轮数/上下文窗口，立即生效）、卡片样式与按钮颜色优化；修复删除 405。
- 嵌入页独立渲染（无系统布局）、标题/头像/消息气泡/UI 美化，优先流式调用，附带历史消息。
- 其他修复：知识库绑定卡片不显示、前端集合接口路径修正、对话/流式事件处理等。

## 1. 模型加载统一（9050 网关）
- 后端新增：`GET /api/v1/models-gateway/models/enabled` 代理 9050 `/v1/models/enabled`，前端不再直连 9050。
- 前端构建页统一解析 providers[].models：
  - chat：生成对话模型下拉；默认（default_chat）自动选中；显示 厂商（cyan Tag）+ 默认（gold Tag）。
  - embedding：按 Provider → Model 分层；默认（default_embedding）标注“默认”并自动选中 Provider/Model。
  - rerank：生成重排下拉；默认（default_rerank）标注“默认”并自动选中；与 chat 字号一致。

## 2. Rerank 集成（硅基流动兼容）
- 新增统一重排供应商工厂：`service/rerank_vendors.py`
  - 网关实现 `GatewayRerankVendor` 调用 `/v1/rerank`，请求体：
    ```json
    {"model": "<rerank-model>", "query": "<query>", "documents": ["doc1", "doc2", ...]}
    ```
  - 响应体：
    ```json
    {"id":"...","results":[{"document":{"text":"..."},"index":0,"relevance_score":0.82}],"tokens":{}}
    ```
  - 输出：`[(index, score)]`，按 score 降序。
- 混合检索接入：`hybrid_search_service.rerank_results`
  - 未指定模型时，从 `/v1/models/enabled` 自动选择 `default_rerank`。
  - 成功则更新各 SearchResult 的 `combined_score`（归一化到 [0,1]），并排序；失败回退领域词加权。

## 3. 构建页（工作室）交互与数据
- 保存/导出职责分离：
  - “保存”= 保存草稿（localStorage），仅用于创建页测试与恢复；不会生成“我的智能体”。
  - “导出”= 生成“我的智能体”，成功后自动清理当前模板草稿。
- 草稿多版本管理：
  - 新存储 `agent_studio_drafts_v2`（按模板 ID 分组，最多 20 条）。
  - 底部操作区采用弹出式“草稿”菜单：保存草稿、另存为、加载、删除。
  - 首次进入（模板创建模式）自动尝试恢复草稿。
- 对话测试“无响应”修复：
  - 前端 SSE 回调在 `execute` 阶段实时渲染模型结果；错误事件显示提示；`workflow_end` 兜底提示完成。
  - 服务端 `step_execute` 优先 `model.invoke(messages)`（多轮消息体），失败回退 `agent.arun`。
- 知识库绑定卡片：
  - 修复集合接口兜底路径为 `/knowledge/collections`。
  - 知识库助手模板（kind=knowledge）强制显示“知识库绑定”卡片（即使后端 `requirements` 缺失）。
