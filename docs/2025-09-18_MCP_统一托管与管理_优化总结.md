# 2025-09-18 MCP 统一托管与管理 优化总结

## 9050 网关增强（MCP 共享运行时）
- 新增运行时注册表（表：`mcp_instances`，AutoMigrate），登记 tenant/name/transport/endpoint/prefix/status/tools/metadata/心跳。
- 基于 mcp-go 实现 stdio MCP 共享运行时：启动/停止/重启、listTools（实时+缓存）、callTool。
- 新增/完善接口（已在 `/docs` 暴露 OpenAPI）：
  - 同步：
    - `POST /admin/sync-mcp-from-unla`（优先内部端点，失败回落 JWT 端点）
    - `POST /admin/sync-mcp-from-unla-db`（直连 DB，无需鉴权）
  - 注册表：`GET/POST/PUT/DELETE /mcp/registry...`，别名 `GET /mcp/servers`
  - 运行态：`POST /mcp/servers/:name/start|stop`、`GET /mcp/servers/:name/tools`、`POST /mcp/servers/:name/tools/:tool/call`
- 直连 DB 同步修正：表名使用 `unla_mcp_configs`（支持可选前缀，默认 `unla_`）。
- 健壮性：统一 `context.WithTimeout`；移除未导出类型引用；失败回退缓存并返回明确错误。

## Unla 后端（5234/5235）协作优化
- 5234（apiserver）：
  - 新增只读内部端点：`GET /api/internal/mcp/configs`（本机默认可信，`APISERVER_TRUST_LOCAL=false|0|off` 可关闭）。
  - 修复 `Database` 接口缺失 `UpdateMCPInstanceTools` 声明导致的编译错误。
- 5235（mcp-gateway）：
  - 修复使用未导出字段引发的编译问题：新增 `State` getter（`GetMCPServerName`）。
  - 说明：MCP 工具页已切换到 9050，不再触发 5235 的前缀直连（避免 `/playwright/mcp` 404）。

## Unla Web（MCP 工具页）体验与交互优化
- 数据源切换到 9050 共享运行时：
  - 列表：合并 Unla `/api/mcp/configs` 与 9050 `/mcp/registry`，按每个 stdio 服务器展示卡片。
  - 操作：调用 9050 的 `start/stop/restart`、`listTools`；“查看工具”弹窗展示实时/缓存工具列表。
- 卡片样式重构（现代化）：
  - 圆角、细边、磨砂背景、hover 阴影；左侧图标底板；右侧**更小**的状态徽章（`text-[10px]`、小圆点）。
  - 右上“查看工具”按钮缩小、移除图标；顶部“一键添加 Playwright”按钮移除。
  - 底部操作按钮风格统一：
    - 启动：绿色 `success/solid`
    - 停止：红色 `danger/solid`
    - 重启：`secondary/solid`（与启动、停止区分）
    - 忙碌态显示 Spinner 并禁用按钮。
- 搜索优化：支持按 serverName/配置/租户筛选。

## 同步与运行流程（推荐）
1. 直连 DB 同步：`POST /admin/sync-mcp-from-unla-db`（可选 `{"prefix":"unla_"}`）。
2. 启动 MCP：`POST /mcp/servers/:name/start`。
3. 查看工具：`GET /mcp/servers/:name/tools`。
4. 调用工具：`POST /mcp/servers/:name/tools/:tool/call`。

（可选）HTTP 同步：`POST /admin/sync-mcp-from-unla`（优先内部免鉴权端点、失败才回落需要 JWT 的受保护端点）。

## 已修复问题
- 9050 编译问题：`time.WithTimeout` → `context.WithTimeout`；移除未导出的类型引用。
- 5234 接口声明缺失导致编译错误（`UpdateMCPInstanceTools`）。
- 直连同步表名错误（42P01）修正为 `unla_mcp_configs`。
- MCP 工具页遗留前缀直连 5235 导致 404 的问题规避。

## 后续建议
- 将聊天页工具调用也切换到 9050（REST），彻底移除 5235 依赖。
- 9050 运行时引入轻量沙箱（nsjail/bwrap），增强资源/网络限制与审计。
- MCP 工具页可引入右侧抽屉式工具面板、在线状态自动刷新、错误日志查看等。
