- **[index.html](./index.html)** - 主页面，包含所有文档链接和使用说明
- **[swagger.html](./swagger.html)** - Swagger UI界面，支持交互式API测试

## 🛠️ 主要API模块

基于文档生成时的API结构，系统包含以下主要模块：

### 核心功能
- **QA问答** (`/api/v1/qa/`) - 智能问答核心接口
- **对话管理** (`/api/v1/conversations/`) - 对话历史和管理
- **知识库** (`/api/v1/knowledge/`) - 知识库管理和检索

### 系统管理
- **配置管理** (`/api/v1/config/`) - 系统配置接口
- **模型管理** (`/api/v1/models/`) - AI模型配置
- **存储管理** (`/api/v1/storage/`) - 文件存储接口

### 数据管理
- **论文管理** (`/api/v1/papers/`) - 论文上传和管理
- **知识图谱** (`/api/v1/graph/`) - 知识图谱操作
- **统计信息** (`/api/v1/stats/`) - 系统统计数据
