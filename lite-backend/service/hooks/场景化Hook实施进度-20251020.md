### 2. 政策问答场景 Pre-Hooks (3/3完成)

#### 2.1 PolicySensitiveWordCheckHook ✅

**文件**: `service/hooks/pre_hooks/policy_sensitive_word_check.py`

**功能**:
- 检测政策查询中的敏感词（政治、法律、民族宗教等）
- 支持本地敏感词库 + 外部API的混合检测
- 可配置的检测级别（strict/moderate/loose）
- 分类敏感词管理
- 违规日志记录

**核心配置项**:
```yaml
check_level: strict/moderate/loose
block_on_detection: true/false
categories: [political, legal, ethnic]
use_external_api: true/false
```

#### 2.2 PolicyMetadataExtractorHook ✅

**文件**: `service/hooks/pre_hooks/policy_metadata_extractor.py`

**功能**:
- 从查询中提取政策元数据（编号、日期、机关、级别等）
- 支持正则、NLP、LLM的混合提取策略
- 提取的元数据增强检索上下文
- 非强制提取（失败不阻断流程）

**提取字段**:
- policy_number - 政策编号
- issue_date - 发布日期
- issuing_agency - 发文机关
- policy_level - 政策级别（国家/省/市）
- effective_date - 生效日期

**核心配置项**:
```yaml
required: false  # 是否强制要求
extraction_method: hybrid  # regex/nlp/llm/hybrid
use_external_tool: true/false
min_confidence: 0.7
```

#### 2.3 PolicyQueryNormalizationHook ✅

**文件**: `service/hooks/pre_hooks/policy_query_normalization.py`

**功能**:
- 去除冗余词汇（语气词、口语化表达）
- 展开政策领域缩写（国发→国务院发布的）
- 标准化政策术语
- 提取关键词和实体

**标准化操作**:
1. remove_redundant_words - 去除冗余词
2. expand_abbreviations - 展开缩写
3. standardize_terms - 标准化术语
4. extract_keywords - 提取关键词

**核心配置项**:
```yaml
operations: [remove_redundant_words, expand_abbreviations, ...]
use_nlp: true/false
preserve_original: true/false
```

### 3. 政策问答场景 Post-Hooks (1/3完成)

#### 3.1 PolicyCitationEnhancementHook ✅

**文件**: `service/hooks/post_hooks/policy_citation_enhancement.py`

**功能**:
- 检测输出中的政策引用
- 补充完整的引用信息（名称、机关、日期等）
- 添加官方文档链接
- 验证引用的准确性
- 统一引用格式

**引用格式**:
- minimal - 只有编号
- standard - 编号 + 名称 + 链接
- detailed - 编号 + 名称 + 机关 + 日期 + 链接

**核心配置项**:
```yaml
auto_enhance: true/false
citation_format: standard/detailed/minimal
add_links: true/false
validate_citations: true/false
use_external_db: true/false
```

## 🎯 核心特性

### 已实现的核心特性

1. **分级敏感词检测** - 支持strict/moderate/loose三级检测
2. **混合提取策略** - 正则+NLP+LLM的智能组合
3. **非阻塞增强** - 元数据提取失败不中断流程
4. **查询标准化** - 多步骤标准化处理
5. **引用增强** - 自动补充政策详细信息
6. **工具集成** - 支持调用外部API和MCP工具
7. **配置驱动** - 所有行为可通过配置调整
8. **详细日志** - 完整的执行过程记录

### 技术亮点

1. **混合检测策略**: 本地快速检测 + API深度检测
2. **渐进式提取**: 正则→NLP→LLM的降级策略
3. **上下文增强**: 提取的信息注入到context供后续使用
4. **优雅降级**: 外部工具失败时自动回退到本地逻辑
5. **元数据驱动**: 详细的执行元数据用于监控和调试
