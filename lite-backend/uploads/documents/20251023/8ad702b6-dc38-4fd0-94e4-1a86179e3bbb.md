# 敏感词服务API文档

## 基础信息

- **Base URL**: `http://127.0.0.1:8001`
- **词库规模**: 49,976个敏感词
- **响应时间**: ~8ms
- **服务版本**: v1.0.0

## 核心接口

### 敏感词检测（主要接口）

**接口地址**: `POST /v1/sensitive/check`

**请求示例**:
```bash
curl -X POST "http://127.0.0.1:8001/v1/sensitive/check" \
  -H "Content-Type: application/json" \
  -d '{
    "content": "要检测的文本内容",
    "options": {
      "return_details": true
    }
  }'
```

**响应格式**:
```json
{
  "has_sensitive": true,
  "should_reject": false,
  "masked": "要检测的***内容",
  "detected_count": 1,
  "hits": ["文本"],
  "processing_time_ms": 8.14
}
```

**字段说明**:
- `has_sensitive`: 是否包含敏感词
- `should_reject`: 是否建议拒绝（当前固定false）
- `masked`: 屏蔽后的文本（***替换）
- `detected_count`: 检测到的敏感词数量
- `hits`: 命中的敏感词列表（仅当return_details=true时返回）
- `processing_time_ms`: 处理耗时（毫秒）

## 代码集成示例

### JavaScript/TypeScript
```javascript
// 前端调用示例
async function checkSensitiveWords(text) {
  const response = await fetch('http://127.0.0.1:8001/v1/sensitive/check', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      content: text,
      options: { return_details: true }
    })
  });
  
  if (!response.ok) {
    throw new Error(`HTTP error! status: ${response.status}`);
  }
  
  return await response.json();
}
```

### Python
```python
import requests

def check_sensitive_words(text):
    response = requests.post(
        'http://127.0.0.1:8001/v1/sensitive/check',
        json={
            'content': text,
            'options': {'return_details': True}
        }
    )
    response.raise_for_status()
    return response.json()
```

## 注意事项

1. **文本长度限制**: 单次检测文本不超过50KB
2. **字符编码**: 统一使用UTF-8编码
3. **缓存机制**: 服务启动时自动加载词库到内存，词库更新后需调用缓存重建接口
4. **性能**: 内存缓存模式，单次检测耗时约8ms
5. **依赖**: 需要PostgreSQL数据库连接

## 错误处理

- **500错误**: 检测失败，通常是数据库连接问题
- **422错误**: 请求参数格式错误
- **文本过长**: 超过50KB会返回验证错误
