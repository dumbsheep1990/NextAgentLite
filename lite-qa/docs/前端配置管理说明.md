# 前端配置管理说明

## 概述

前端项目已经实现了完整的配置注入机制，支持通过环境变量集中管理所有配置项，包括版本信息、API地址、WebSocket地址、CORS设置等。

## 环境变量文件

### 配置文件优先级

1. `.env.local` - 本地开发配置（优先级最高，不应提交到版本控制）
2. `.env.development` - 开发环境配置
3. `.env.production` - 生产环境配置
4. 代码中的默认值（优先级最低）

### 主要配置项

#### 应用基本信息
```bash
VITE_APP_NAME=地聚物材料智能问答系统
VITE_APP_VERSION=1.2.0
VITE_APP_DESCRIPTION=基于大模型的材料科学智能问答平台
VITE_APP_AUTHOR=GAC Team
```

#### 后端服务配置
```bash
VITE_API_BASE_URL=http://localhost:8000
VITE_API_VERSION=v1
VITE_API_TIMEOUT=30000
```

#### WebSocket 和 SSE 配置
```bash
VITE_WS_URL=ws://localhost:8000
VITE_SSE_URL=http://localhost:8000
VITE_SSE_RECONNECT_INTERVAL=3000
VITE_SSE_MAX_RECONNECT_ATTEMPTS=10
```

#### 开发服务器配置
```bash
VITE_DEV_PORT=3000
VITE_DEV_HOST=localhost
VITE_DEV_OPEN=true
```

#### 生产环境配置
```bash
VITE_PROD_PORT=4173
VITE_PROD_HOST=0.0.0.0
```

#### CORS 配置
```bash
VITE_CORS_ORIGINS=http://localhost:3000,http://127.0.0.1:3000,http://localhost:4173
VITE_CORS_CREDENTIALS=true
```

#### 功能开关
```bash
VITE_ENABLE_GRAPH_VIEW=true
VITE_ENABLE_DUAL_VECTOR=true
VITE_ENABLE_TRANSLATION=true
VITE_ENABLE_VOICE_INPUT=false
VITE_ENABLE_EXPORT=true
```

## 使用方式

### 1. 配置访问

在代码中使用配置：

```typescript
import { APP_CONFIG, getApiUrl, getSSEUrl } from '../config/appConfig';

// 使用应用配置
console.log(APP_CONFIG.app.name);
console.log(APP_CONFIG.app.version);

// 使用API配置
const apiUrl = getApiUrl('documents');
const sseUrl = getSSEUrl('sse/document-status/session123');

// 使用功能开关
if (APP_CONFIG.features.enableGraphView) {
  // 渲染图谱视图
}
```

### 2. 环境判断

```typescript
import { isDevelopment, isProduction, getCurrentEnv } from '../config/appConfig';

if (isDevelopment()) {
  console.log('开发环境');
}

if (isProduction()) {
  console.log('生产环境');
}
```

### 3. 版本信息

```typescript
import { APP_VERSION, getFullVersionInfo } from '../config/version';

console.log(APP_VERSION.version);
console.log(getFullVersionInfo());
```

## PM2 管理

### 启动命令

```bash
# 启动开发环境
npm run pm2:dev

# 启动生产环境
npm run pm2:prod

# 停止所有服务
npm run pm2:stop

# 重启服务
npm run pm2:restart

# 查看日志
npm run pm2:logs

# 查看状态
npm run pm2:status
```

### PM2 进程

- `mat-qa-dev`: 开发环境服务（端口3000）
- `mat-qa-prod`: 生产环境预览服务（端口4173）

## 配置最佳实践

### 1. 环境特定配置

- 开发环境启用详细日志和调试功能
- 生产环境关闭调试信息，启用性能优化
- 使用环境变量控制功能开关

### 2. 安全考虑

- 不要在前端环境变量中存储敏感信息
- 生产环境启用CSP等安全配置
- 限制CORS来源域名

### 3. 性能优化

- 生产环境启用代码分割
- 合理配置缓存策略
- 使用CDN加速静态资源

## 故障排查

### 常见问题

1. **配置不生效**
   - 检查环境变量是否以 `VITE_` 开头
   - 确认配置文件路径正确
   - 重启开发服务器

2. **API连接失败**
   - 检查 `VITE_API_BASE_URL` 配置
   - 确认后端服务是否运行
   - 检查网络连接和防火墙设置

3. **PM2 启动失败**
   - 检查 Node.js 版本
   - 确认端口未被占用
   - 查看 PM2 日志文件
