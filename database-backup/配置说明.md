# 配置说明文档

## Elasticsearch 索引命名

### 当前使用的索引名称

项目使用以下 Elasticsearch 索引（前缀 `mat_qa_`）：

```
mat_qa_chunks              - 文档分块索引
mat_qa_general_vectors     - 通用向量索引 (1024维)
mat_qa_domain_vectors      - 领域向量索引 (768维)
mat_qa_papers              - 论文数据索引
mat_qa_documents           - 文档索引
mat_qa_retrieval_cache     - 检索缓存索引
mat_qa_media               - 媒体文件索引
```

### 向量维度配置

- **通用向量**: 1024 维（text-embedding-v4）
- **领域向量**: 768 维（MatBERT）

这些配置在代码中实际使用：
- `lite-backend/db/elasticsearch_qa_dataset_mappings.py`
- `lite-backend/core/config_optimized.py`

### 说明

- `mat_qa_` 前缀是历史遗留命名，但仍是功能性配置
- 这些索引名称与项目代码紧密关联
- **不是硬编码的示例数据**，而是运行时实际使用的配置

## MinIO 存储桶命名

### 当前使用的存储桶

项目使用以下 MinIO 存储桶（前缀 `policy-qa-`）：

```
policy-qa-documents         - 文档存储
policy-qa-media             - 多媒体文件
policy-qa-thumbnails        - 缩略图（公共读取）
policy-qa-knowledge-graph   - 知识图谱资源
policy-qa-reports           - 生成报告
policy-qa-backups           - 系统备份
policy-qa-logs              - 日志归档
policy-qa-cache             - 临时缓存
```

### 配置位置

这些存储桶名称定义在环境变量中：
```bash
# lite-backend/.env
MINIO_DOCUMENTS_BUCKET="policy-qa-documents"
MINIO_MEDIA_BUCKET="policy-qa-media"
MINIO_THUMBNAILS_BUCKET="policy-qa-thumbnails"
...
```

### 说明

- `policy-qa-` 前缀是历史遗留命名
- 这些桶名称是 `.env` 配置文件中的实际配置
- 应用运行时会使用这些桶名
- **不是硬编码的示例数据**

## 如何修改命名？

如果需要统一修改前缀（如改为 `nextagent-` 或 `lite-`），需要：

### 修改 Elasticsearch 索引前缀

1. 修改代码中的索引名称常量：
   ```python
   # lite-backend/db/elasticsearch_qa_dataset_mappings.py
   QA_PAIRS_VECTOR_INDEX = "nextagent_qa_pairs_vectors"
   QA_DATASETS_INDEX = "nextagent_qa_datasets"
   ```

2. 更新初始化脚本：
   ```bash
   # database-backup/init_elasticsearch.sh
   INDICES=(
       "nextagent_qa_chunks"
       "nextagent_qa_general_vectors"
       ...
   )
   ```

### 修改 MinIO 存储桶前缀

1. 修改环境变量：
   ```bash
   # lite-backend/.env
   MINIO_DOCUMENTS_BUCKET="nextagent-documents"
   MINIO_MEDIA_BUCKET="nextagent-media"
   ...
   ```

2. 更新初始化脚本：
   ```bash
   # database-backup/init_minio.sh
   BUCKETS=(
       "nextagent-documents:文档存储"
       "nextagent-media:多媒体文件"
       ...
   )
   ```
