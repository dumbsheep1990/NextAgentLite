## 安全说明

### 生产环境建议

1. **使用HTTPS**:
   - 配置SSL证书
   - 修改所有http为https

2. **限制CORS来源**:
   - 只允许必要的域名
   - 移除开发环境配置 (localhost)

3. **配置防火墙**:
   ```bash
   # 只允许特定端口
   ufw allow 8000/tcp
   ufw allow 3000/tcp
   ```

4. **使用反向代理** (推荐):
   - Nginx/Caddy配置
   - 统一HTTPS入口
   - 隐藏内部端口

## 常见问题

### Q: 无法从外部访问服务
**A**: 检查以下配置：
1. 服务是否监听在 0.0.0.0
2. 防火墙是否开放端口
3. 云服务器安全组是否配置

### Q: CORS错误
**A**: 确认：
1. 后端CORS_ORIGINS包含前端域名
2. 前端corsOrigins配置正确
3. 请求头包含正确的Origin

### Q: 端口冲突
**A**: 修改环境变量：
```bash
# 前端
VITE_DEV_PORT=3001

# 后端
API_PORT=8001
```
