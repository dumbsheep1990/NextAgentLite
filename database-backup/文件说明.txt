================================================================================
快速开始
================================================================================

1. 上传整个 database-backup/ 目录到服务器

2. 导入 PostgreSQL:
   bash import_postgresql_clean.sh

3. 初始化 Elasticsearch:
   bash init_elasticsearch.sh

4. 初始化 MinIO (需要先安装 mc 工具):
   # Linux: wget https://dl.min.io/client/mc/release/linux-amd64/mc && chmod +x mc && sudo mv mc /usr/local/bin/
   # macOS: brew install minio/stable/mc
   bash init_minio.sh

5. 验证导入:
   psql -h <host> -p <port> -U <user> -d zzdsj_demo \
     -c "SELECT COUNT(*) FROM document_categories;"
   
   应该返回: 0 （如果非0，说明导入了错误的文件）
