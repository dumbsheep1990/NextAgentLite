# NextAgentLite 启动说明

## 快速启动

### 一键启动所有服务

**方式一：项目根目录快捷方式**（推荐）
```bash
cd /Users/wxn/Desktop/NextAgentLite
./start.sh
```

**方式二：直接调用完整脚本**
```bash
cd /Users/wxn/Desktop/NextAgentLite
./services/scripts/start_all_services.sh
```

这个脚本会自动：
1. ✅ 检查conda环境（zzdsj-lite）
2. ✅ 检查Node.js和npm
3. ✅ 检查并安装前端依赖
4. ✅ 检查后端Python包
5. ✅ 检查端口占用情况
6. ✅ 启动后端服务（lite-backend:8000）
7. ✅ 启动DataGraph服务（9622）- 可选
8. ✅ 启动前端服务（lite-qa:3000）

### 停止所有服务

```bash
./stop.sh
# 或
./services/scripts/stop_all_services.sh
```

### 检查服务状态

```bash
./status.sh
# 或
./services/scripts/check_services.sh
```

显示：
- 进程运行状态和资源占用
- HTTP服务可用性
- 最近日志错误

## 环境要求

### 1. Conda环境

**必需**: conda环境 `zzdsj-lite` (Python 3.12)

```bash
# 创建环境
conda create -n zzdsj-lite python=3.12

# 激活环境
conda activate zzdsj-lite

# 安装依赖
cd lite-backend
pip install -r requirements.txt
```

**重要依赖**:
- fastapi
- uvicorn
- sqlalchemy
- elasticsearch
- agno
- crawl4ai
- readability-lxml

### 2. Node.js环境

**必需**: Node.js 18+ 和 npm

```bash
# 安装前端依赖
cd lite-qa
npm install
```

### 3. 数据库和服务

**运行时需要**:
- PostgreSQL 17+ (with pgvector)
- Elasticsearch 9+
- Redis 6+

**可选**:
- MinIO (对象存储)

```
                 │
                 ▼
    ┌────────────────────────────────┐
    │   各个后端微服务                │
    │                                 │
    │  • DataGraph (9622)             │
    │  • LLM Gateway (9050)           │
    │  • DeepScrape (3001)            │
    │  • Unla Web (5173)              │
    └─────────────────────────────────┘
```

## 服务访问地址

- **LLM Gateway直连**: http://localhost:9050

## 日志文件

所有日志存储在 `logs/` 目录：

- `logs/backend.log` - 后端服务日志
- `logs/frontend.log` - 前端服务日志
- `logs/datagraph.log` - DataGraph服务日志
- `logs/*.pid` - 进程ID文件

### 查看实时日志

```bash
# 查看所有日志
tail -f logs/*.log

# 查看后端日志
tail -f logs/backend.log

# 查看前端日志
tail -f logs/frontend.log

# 查看DataGraph日志
tail -f logs/datagraph.log

# 过滤错误日志
tail -f logs/backend.log | grep -i error
```

## 常用操作

### 启动特定服务

**只启动后端**:
```bash
cd lite-backend
/opt/anaconda3/envs/zzdsj-lite/bin/python main.py
```

**只启动前端**:
```bash
cd lite-qa
npm run dev
```

**只启动DataGraph**:
```bash
cd lite-backend
bash start_datagraph.sh
```

### 使用PM2管理（开发环境）

```bash
# 启动所有PM2服务
pm2 start ecosystem.config.js

# 查看状态
pm2 status

# 查看日志
pm2 logs

# 停止服务
pm2 stop all

# 重启服务
pm2 restart all
```

**注意**: 当前PM2配置未使用conda环境，建议使用统一启动脚本。

### 端口占用处理

```bash
# 查看端口占用
lsof -i :3000  # 前端
lsof -i :8000  # 后端
lsof -i :9622  # DataGraph

# 停止占用端口的进程
kill -9 $(lsof -ti :8000)
```

## 故障排除

### 1. conda环境不存在

**错误**: `conda环境 zzdsj-lite 不存在`

**解决**:
```bash
conda create -n zzdsj-lite python=3.12
conda activate zzdsj-lite
cd lite-backend
pip install -r requirements.txt
```

### 2. 后端启动失败

**检查**:
```bash
# 查看后端日志
tail -50 logs/backend.log

# 常见原因
# - 数据库未启动
# - 环境变量未配置
# - 端口被占用
# - Python包缺失
```

**解决**:
```bash
# 检查数据库
psql -h localhost -p 5432 -U postgres

# 检查环境变量
cat lite-backend/.env

# 检查端口
lsof -i :8000
```

### 3. 前端编译错误

**错误**: `Module not found` 或编译失败

**解决**:
```bash
cd lite-qa
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### 4. DataGraph启动失败

**检查**:
```bash
# 查看DataGraph日志
tail -50 logs/datagraph.log

# 常见原因
# - conda环境问题
# - API密钥未配置
# - 端口被占用
```

**解决**:
```bash
# 检查conda环境
/opt/anaconda3/envs/zzdsj-lite/bin/python --version

# 检查环境变量
cat lite-backend/.env | grep DATAGRAPH

# 手动启动测试
cd lite-backend
bash start_datagraph.sh
```

### 5. 前端无法连接后端

**检查**:
1. 后端是否正常运行: `curl http://localhost:8000/health`
2. 前端环境变量配置: `cat lite-qa/.env.local`
3. 浏览器Network面板查看实际请求地址

**解决**: 确保前端环境变量正确配置API地址

### 6. API网关代理失败

**错误**: `503 Service Unavailable` 或 `502 Bad Gateway`

**检查**:
```bash
# 检查网关健康
curl http://localhost:8000/api-gateway/health

# 检查目标服务
curl http://localhost:9622/health  # DataGraph
curl http://localhost:9050/health  # LLM Gateway
```

**解决**: 启动相应的目标服务

## 开发模式 vs 生产模式

### 开发模式（当前）

**特点**:
- 前端使用Vite开发服务器（热更新）
- 后端使用uvicorn reload模式
- 服务独立运行，便于调试
- 日志输出到终端和文件

**启动**: `./start_all_services.sh`

### 生产模式（未来）

**特点**:
- 前端构建为静态文件
- Nginx作为统一入口
- PM2或systemd管理进程
- 日志集中管理

**部署**:
```bash
# 构建前端
cd lite-qa
npm run build

# 配置Nginx
nginx -t
nginx -s reload

# 使用systemd管理服务
systemctl start nextagent-backend
systemctl start nextagent-datagraph
```
